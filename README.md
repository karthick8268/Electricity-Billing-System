⚡ Electricity Billing System Using Python

A simple Python application that calculates electricity bills based on the number of units consumed by each customer using a slab-based billing system.

🚀 Features

- Accepts multiple customer details.
- Takes customer names and electricity consumption.
- Calculates bills using slab-based rates.
- Displays customer names, units consumed, and bill amounts.
- Rounds bill amounts to two decimal places.

🛠️ Technologies Used

- Programming Language: Python
- IDE: Visual Studio Code

📊 Billing Structure

The following illustrative rates are used in this project:

Electricity Units| Rate per Unit
First 100 units| ₹1.50
Next 100 units| ₹2.50
Next 300 units| ₹4.00
Above 500 units| ₹6.00

Note: These rates are examples for this project and may not match actual electricity tariffs.

💻 How to Run

1. Install Python 3 on your computer.

2. Clone or download this repository.

3. Open the project folder in Visual Studio Code.

4. Open the terminal.

5. Run the following command:
   
   python main.py

6. Enter the number of customers, their names, and their electricity consumption in units.
